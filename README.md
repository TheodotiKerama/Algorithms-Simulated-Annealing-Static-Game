# Algorithms-Simulated-Annealing-Static-Game

## Disclaimer

This project is a web-based rewrite of the original **Student Separation** game created by **Luke Renaud and Robert Krivelis** for ENCM 507 (Computer Aided Design) at the University of Calgary.

The original game was built in [Processing (Java)](https://processing.org/) and is available at:
[https://github.com/robert-krivelis/Algorithms-Simulated-Annealing-Game](https://github.com/robert-krivelis/Algorithms-Simulated-Annealing-Game)

All game logic, the simulated annealing algorithm, scoring formulas, node mechanics, and game design are directly ported from the original source code. This repository only converts the implementation to HTML, JavaScript, and Vue.js so the game can run in a browser without the Processing IDE.

All credit for the original concept and implementation goes to the original authors.
